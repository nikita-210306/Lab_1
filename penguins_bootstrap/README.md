# Непараметрический бутстрэп медианы

- `Bootstrap_Markin.Rmd` / `.html` — Маркин Никита Алексеевич, Б24-902.
- `Bootstrap_Andreus.Rmd` / `.html` — Андреус Аглая Ашотовна, Б24-902.
- `Explanation_and_speech.md` — объяснение кода и текст выступления.
- `Save_to_pract.ps1` — сохранение Rmd, HTML и объяснения в папку Windows
  `D:\ФБИУКС\R\pract`; существующие одноименные файлы резервируются.
- `Bootstrap_both.zip` — полный комплект, включая CSV с результатами.

Открыть Rmd в RStudio и нажать **Knit**. Для первого запуска:

```r
install.packages(c("palmerpenguins", "ggplot2", "knitr", "rmarkdown"))
```

Данные загружаются из palmerpenguins; дополнительных исходных файлов нет.
Готовые HTML автономны: рисунки встроены. Код показывается в отчете.
Папки `results_Markin` и `results_Andreus` содержат по четыре CSV:
исходную выборку, 10 000 медиан по порядку, 100 строк по B и пять
контрольных строк. Они заново сохраняются при сборке.

## Проверенные результаты

N = 342; n = 80; seed исходной выборки = 2026; seed бутстрэпа = 2027.
Медианы совокупности и выборки: 4050 и 4300 г.
Среднее 10 000 медиан: 4287,33875 г; стандартная ошибка: 187,8657772 г;
бутстрэп-смещение: −12,66125 г; процентильный интервал: [3950; 4600] г;
ширина: 650 г. Использован стандартный алгоритм квантилей R, type = 7.

Выполнен повышенный вариант: B = 100, 200, …, 10 000. Используются
вложенные начала одной последовательности; повторного моделирования
для разных B нет. Объем каждой бутстрэп-выборки остается 80.

Численные значения итоговой таблицы совпали с присланным образцом
в пределах его округления. Для двух файлов совпадают все 10 000 медиан
и все 100 строк исследования устойчивости. Проверены сборка HTML,
отдельное исполнение извлеченного R-кода и повторяемость результатов.
Среда проверки: R 4.5.0, palmerpenguins 0.1.1, ggplot2 3.5.1.

## Сопоставление с образцом

1. В ячейке ширины интервала при B = 100 в образце находилось `means4[1]`.
   В отчетах выведено правильное число: 4544,0625 − 4000 = 544,0625 г.
2. График Bias в образце имеет отрицательные значения, хотя PDF требует
   абсолютного отклонения. По согласованию включены оба графика:
   обязательный абсолютный и дополнительный знаковый. Они явно различены.
3. Границы интервалов гистограмм заданы явно, чтобы версии ggplot2
   не меняли форму рисунков. Частоты исходных десяти столбцов:
   4, 10, 15, 7, 8, 14, 6, 6, 9, 1. Для бутстрэп-гистограммы — 30
   столбцов; два высоких пика содержат 1451 и 1497 медиан, как в образце.
4. В графике ЭФР для сравнения с образцом соединяются рассчитанные значения
   в наблюдаемых точках. Сама эмпирическая функция ступенчатая; это
   пояснено в тексте. Добавлены названия, единицы и легенды по условию.
