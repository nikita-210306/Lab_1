# Объяснение практикума

Работа посвящена непараметрическому бутстрэпу медианы. Он позволяет по
одной исходной выборке оценить разброс медианы и построить процентильный
доверительный интервал. Предположение о нормальном распределении массы
для этой процедуры не вводится.

Оба Rmd выполняют одинаковую последовательность случайных извлечений:
2026 для исходной выборки, 2027 для бутстрэпа. Различаются имена переменных,
часть комментариев, подпись автора и цвета. Математические операции и их
порядок одинаковы, поэтому результаты совпадают.

## 1. Как запустить

Открыть нужный Rmd в RStudio и нажать **Knit**. Формат результата — HTML.
Код, таблицы и рисунки видны в отчете; графики встроены в HTML.

Если пакетов нет, один раз выполнить в консоли RStudio:

```r
install.packages(c("palmerpenguins", "ggplot2", "knitr", "rmarkdown"))
```

Дополнительные CSV/XLSX для запуска не нужны. Папки `results_Markin` и
`results_Andreus` создаются автоматически; в них сохраняются исходная
выборка, вся последовательность медиан и результаты для разных B.

## 2. Подготовка совокупности

```r
penguins[!is.na(penguins$body_mass_g), c("species", "body_mass_g")]
```

`is.na()` определяет пропуски, `!` меняет условие на противоположное.
Остаются строки с известной массой; выбираются два столбца: вид и масса.
`as.data.frame()` преобразует результат в обычную таблицу. Команда
`rownames(population) <- NULL` сбрасывает старые номера строк. Она не
переставляет строки. Объем полученной совокупности равен 342.

Вид сохранен как характеристика записи, но стратификация не используется:
в этом практикуме все извлечения простые случайные.

## 3. Исходная выборка

```r
set.seed(2026)
sample_idx <- sample.int(342, size = 80, replace = TRUE)
initial_sample <- population[sample_idx, , drop = FALSE]
```

`set.seed()` устанавливает исходное состояние генератора. Он не делает
выборку «неслучайной»: повторяемой становится реализация случайной
процедуры. `sample.int()` выбирает номера от 1 до 342. Аргумент `size = 80`
задает число извлечений, `replace = TRUE` разрешает возвращение.

Квадратные скобки выбирают указанные строки. Пропуск после запятой
означает «все столбцы». `drop = FALSE` сохраняет табличный формат.
Повторяющиеся номера дают повторяющиеся строки и сохраняются в выборке.

Медианы вычисляет `median()`. Получается 4050 г для всей совокупности
и 4300 г для выборки. Разность 250 г — отличие этой выборочной оценки
от эталона. Это не бутстрэп-смещение.

## 4. Первые графики

Эмпирическая функция распределения показывает долю значений, не
превышающих заданную массу. На первой диаграмме сравниваются функции
по 342 и по 80 наблюдениям. Из-за случайности отбора и повторений
частоты различаются, поэтому кривые и медианы могут не совпадать.

Для рисунка сортируются копии векторов масс через `sort()`, а накопленные
относительные частоты задаются как `seq_along(x) / length(x)`.
`geom_line()` соединяет эти точки, как в присланном образце; при
совпадающих массах получаются вертикальные участки. Сама математическая
эмпирическая функция является ступенчатой. Исходные таблицы не сортируются
и не изменяются. `geom_vline()` добавляет вертикальные линии медиан.

`geom_histogram()` на втором графике считает частоты масс в интервалах.
Выбранные границы явно вычислены по минимуму и максимуму: это позволяет
сохранить те же столбцы в разных версиях ggplot2. Частоты десяти столбцов:
4, 10, 15, 7, 8, 14, 6, 6, 9, 1; в сумме 80.

## 5. Бутстрэп

```r
boot_medians <- numeric(10000)
set.seed(2027)
for (i in seq_len(10000)) {
  boot_idx <- sample.int(80, size = 80, replace = TRUE)
  bootstrap_sample <- initial_sample[boot_idx, , drop = FALSE]
  boot_medians[i] <- median(bootstrap_sample$body_mass_g)
}
```

`numeric(10000)` заранее создает числовой вектор для результатов.
В цикле 10 000 раз берется выборка из 80 позиций исходной выборки.
После каждого отбора сохраняется одна медиана. Вектор содержит медианы,
а не массы всех повторно выбранных птиц.

Выбирать из `population` нельзя: тогда моделировалось бы повторное
обследование известной совокупности, а не неопределенность данной
исходной выборки. Повторно задавать `set.seed(2027)` внутри цикла тоже
нельзя: это каждый раз воспроизводило бы один и тот же набор индексов.

При четном объеме 80 медиана — среднее 40-го и 41-го упорядоченных
значений. Массы дискретны; поэтому бутстрэп-медианы повторяются и их
гистограмма имеет выраженные пики. Нормальная форма не требуется.

## 6. Основные результаты

```r
mean_boot <- mean(boot_medians)
se_boot <- sd(boot_medians)
bias_boot <- mean_boot - med_sample
ci_boot <- quantile(boot_medians, c(0.025, 0.975), type = 7)
```

- `mean()` дает среднее бутстрэп-медиан: **4287,33875 г**. Это центр
  полученного бутстрэп-распределения, а не медиана совокупности.
- `sd()` дает стандартное отклонение бутстрэп-медиан: **187,8657772 г**.
  Это оценка стандартной ошибки медианы. Она описывает изменчивость
  оценки, а не разброс масс отдельных пингвинов.
- Разность среднего и исходной выборочной медианы дает оценку
  бутстрэп-смещения: **−12,66125 г**.
- `quantile()` на уровнях 0,025 и 0,975 дает границы процентильного
  интервала: **[3950; 4600] г**. `type = 7` явно закрепляет стандартный
  способ вычисления квантилей R с линейной интерполяцией.
- Ширина равна верхней границе минус нижняя: **650 г**.

Для построения интервала не используется формула среднего ± 1,96 SE.
Границы непосредственно берутся из распределения бутстрэп-медиан.
Интерполяция объясняет дробные границы вроде 4544,0625 г при B = 100.

Медиана совокупности 4050 г находится внутри полученного интервала.
Один интервал не позволяет проверить фактическое покрытие 95%:
для такой проверки понадобились бы многие независимые исходные выборки.

## 7. Вложенные значения B

```r
prefix <- boot_medians[seq_len(b)]
```

Для каждого B выбираются первые B уже сохраненных медиан. Нового
моделирования нет. Поэтому результат для B = 2000 включает первые 1000
результатов, использованных при B = 1000, и следующие 1000.

Выполняются все 100 значений B от 100 до 10 000 с шагом 100. В итоговой
таблице оставлены пять контрольных значений, как требует условие.
Начальный объем 80 не меняется: B — число повторений, а не размер выборки.

Устойчивость среднего оценивается абсолютным отклонением от результата
при 10 000 повторениях. Для B = 100, 1000, 2000, 5000 и 10 000 оно равно
24,16125; 12,09875; 2,61125; 0,08625 и 0 г соответственно.
Ноль в последней точке появляется потому, что результат сравнивается
сам с собой; он не означает отсутствия ошибки относительно совокупности.

Три разных понятия нельзя смешивать:

| Показатель | Что вычитается | Значение или смысл |
|---|---|---|
| Бутстрэп-смещение | Среднее 10 000 медиан − исходная медиана | −12,66125 г |
| Абсолютное отклонение по условию | Модуль разности среднего первых B и среднего 10 000 | Всегда ≥ 0 |
| Знаковая разность из графика Bias | Среднее первых B − среднее 10 000 | Может быть отрицательной |

По согласованию в отчете приведены оба графика вычислительной разности.
На рисунке 4 — обязательное абсолютное отклонение. В дополнении —
знаковая разность, соответствующая присланной кривой Bias.

## 8. Почему B не устраняет всю неопределенность

Чем больше B, тем точнее описывается бутстрэп-распределение данной
выборки. Но новая информация о генеральной совокупности не появляется.
Поэтому оценка не обязана приближаться к эталону 4050 г, стандартная
ошибка не стремится к нулю, а интервал не обязан сужаться.

Ширина по пяти контрольным B: 544,0625; 600,625; 650; 675; 650 г.
Эта последовательность прямо показывает, что ширина немонотонна.
В присланной таблице первая ячейка ширины содержала `means4[1]`;
правильное расчетное число — 544,0625 г.

## 9. Как различаются файлы

| Назначение | Маркин | Андреус |
|---|---|---|
| Массы исходной выборки | `sample_mass` | `observed_masses` |
| Сохраненные бутстрэп-медианы | `boot_medians` | `median_repeats` |
| Медиана совокупности | `med_population` | `population_median` |
| Медиана выборки | `med_sample` | `sample_median` |
| Среднее бутстрэп-медиан | `mean_boot` | `average_median` |
| Таблица по всем B | `result_grid` | `stability_results` |
| Итоговая таблица | `summary_table` | `comparison_table` |

Имена не меняют алгоритм. Состав исходной выборки, все 10 000 медиан,
100 строк исследования устойчивости и итоговая таблица у обоих файлов
совпадают. Применяются базовые средства R, ggplot2 для графиков,
palmerpenguins для данных и knitr/rmarkdown для оформления.

# Текст выступления

Тема моей работы — непараметрический бутстрэп медианы массы тела
пингвинов. Цель — оценить медиану и ее неопределенность, а также проверить,
как результаты зависят от числа бутстрэп-повторений.

Генеральной совокупностью по условию считаются 342 записи Palmer Penguins
с известной массой. Из этой совокупности при зерне 2026 сформирована
выборка из 80 извлечений с возвращением. Медиана совокупности равна
4050 граммам, а медиана исходной выборки — 4300 граммам. Их различие
объясняется случайным составом выборки и повторениями наблюдений.

Затем при зерне 2027 выполнены 10 000 бутстрэп-повторений. В каждом
повторении 80 наблюдений выбираются с возвращением только из исходной
выборки и вычисляется медиана. Все медианы сохранены в порядке получения.

Среднее бутстрэп-медиан составляет 4287,33875 грамма. Стандартная ошибка
медианы — примерно 187,87 грамма, а бутстрэп-смещение относительно
выборочной медианы — минус 12,66125 грамма. Процентильный 95%-й интервал
получен по квантилям уровней 2,5 и 97,5 процента. Его границы — 3950 и
4600 граммов, ширина — 650 граммов. Медиана совокупности находится внутри.

Для исследования устойчивости использованы первые 100, 200 и далее
вплоть до 10 000 медиан той же последовательности. Бутстрэп заново не
запускался. При 100 повторениях среднее отличается от результата при
10 000 на 24,16125 грамма, а при 5000 — только на 0,08625 грамма.
Однако изменения не обязаны быть монотонными; ширина интервала тоже
может как увеличиваться, так и уменьшаться.

Главный вывод: увеличение числа повторений повышает вычислительную
устойчивость бутстрэпа, но не увеличивает исходную выборку и не устраняет
ее отличие от совокупности. Поэтому оно не гарантирует приближения оценки
к истинной медиане или сужения интервала на каждом шаге. По одному
интервалу также нельзя установить фактическую вероятность покрытия 95%.
Все выводы работы относятся именно к заданным 342 записям.
