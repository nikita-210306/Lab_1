# Практикум: формирование выборки

`Markin_penguins_sampling.Rmd` — выполненный практикум по условию
`practicum_penguins_sampling.pdf`: все шесть этапов, исходный R-код,
два рисунка с восемью гистограммами и ответы на пять вопросов заключения.
`Markin_penguins_sampling.html` — готовый отчет для просмотра.

Для запуска в RStudio:

```r
install.packages(c("palmerpenguins", "knitr", "rmarkdown")) # Один раз
rmarkdown::render("Markin_penguins_sampling.Rmd")
```

Можно открыть Rmd и нажать **Knit**. Pandoc поставляется вместе с RStudio.
Дополнительные XLSX/CSV для работы не требуются. В готовом отчете видны
код, таблицы, графики и выводы.

Проверено на R 4.5.0 и palmerpenguins 0.1.1. Начальное значение генератора:
20261023, алгоритмы Mersenne-Twister / Inversion / Rejection.

Основные контрольные результаты: N = 342, разведочное среднее = 4348 г,
исправленная разведочная дисперсия = 635412,5 г², n = 89.
Объемы страт Adelie / Chinstrap / Gentoo: 39 / 18 / 32.
Каждый метод использует 1000 реализаций одинакового общего объема.

Проверены сборка отчета, отдельное исполнение извлеченного R-кода,
точное воспроизведение четырех массивов оценок и сравнительной таблицы.
Данные, разведочные характеристики и объем независимо сверены по исходному
CSV пакета. Для четырех методов стандартные ошибки согласуются с
теоретическими ошибками соответствующих схем отбора.
