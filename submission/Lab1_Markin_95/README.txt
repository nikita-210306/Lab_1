ПОВТОРНЫЙ ЗАПУСК
1. Распакуйте весь архив в одну папку и сделайте ее рабочей папкой R.
   Пути в Rmd и R заданы относительно этой папки: data/variant95.xlsx.
2. При необходимости установите пакеты:
   install.packages(c("openxlsx", "ggplot2", "knitr", "rmarkdown"))
   Для сборки нужен Pandoc; он входит в RStudio.
3. Отдельный запуск расчетов: source("Markin_LR1_var95.R", encoding="UTF-8")
   либо из терминала этой папки: Rscript Markin_LR1_var95.R
   Скрипт сохраняет расчетные таблицы и восемь рисунков в results/.
4. Сборка отчета:
   rmarkdown::render("Markin_LR1_var95.Rmd", output_format = "all")
   Получаются HTML и DOCX. Для только HTML: output_format="html_document".
5. При изменении Rmd обновите отдельный R-файл:
   knitr::purl("Markin_LR1_var95.Rmd", "Markin_LR1_var95.R", documentation=0)
6. В Word разрешите обновление полей при открытии. Для обновления оглавления
   вручную: Ctrl+A, F9; выберите обновление целиком. Оглавление является полем TOC,
   заголовки используют стили Word, номера страниц — поле PAGE.

ЧТО ОСТАЛОСЬ ДЛЯ ПОЛНОГО ВЫПОЛНЕНИЯ МЕТОДИЧКИ
Официальные ряды за январь–август 2026 не подтверждены. Доступ к указанному
сайту Банка России 17.10.2026 вернул HTTP 403 (CONNECT). Объединенный PDF —
учебные материалы по R, а числа из чужого примера не являются проверенным
первоисточником. По требованию пользователя неподтвержденные числа заменены NA.
В Rmd найдите комментарии "ЗАПОЛНИТЬ": official_obs, official_exp, official_ITS,
official_IPO, official_IPN — по 8 значений за январь–август, без округления сверх
точности публикации. Укажите official_date и official_precision. Источник:
https://www.cbr.ru/Collection/Collection/File/62282/inFOM_26-08.pdf
https://www.cbr.ru/analytics/dkp/inflationary_expectations/
После заполнения пересоберите Rmd, обновите R через purl и текст интерпретации.
До этого рисунки 7–8 содержат только учебные сентябрьские точки, официальные
августовские уровни и разности в таблице динамики отсутствуют. Это ограничение
указано в самом отчете. Полностью завершенной историческую часть считать нельзя.

В исходном XLSX отсутствует характеристика дохода на одного члена семьи.
В соответствии с индивидуальным запросом использованы пять квантильных групп
рассчитанного дохода; замена явно обозначена как учебное допущение.
